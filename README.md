# ColdLine.C

Jogo de acao top-down em pixel art, inspirado em Hotline Miami. Voce e um policial disposto a limpar as ruas de ColdLine prendendo e neutralizando criminosos.

A top-down pixel art action game inspired by Hotline Miami. You play as a police officer determined to clean up the streets of ColdLine by arresting and neutralizing criminals.
